# All things DaVinci Resolve

All the tools and utilities I created for myself that I highlight on my [Youtube channel](https://www.youtube.com/@FiguringItOutWithP-O) are found here.

Feel free to use them for your projects as you see fit. These are free to use!

Most of the tools here have a video explaining what they do and how to use it, so if you need more information about them, I suggest you go watch the associated video first. If you still have questions or if something is missing, you can either leave a comment on the Youtube video or open up an [issue](https://github.com/pier-oliviert/davinci-resolve/issues) here.

Contributions are welcome! Just fork the repo and submit a PR.
